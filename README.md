# REX Medical Complex — Frontend

React 18 + Vite + Tailwind. Docs `docs/` folder mein hain: `PRD.md`, `architecture.md`, `rules.md`, `phases.doc.md`, `design.md`, `memory.md`.

```bash
npm install
npm run dev        # local (API: http://localhost:5000, ya VITE_API_URL)
npm run build      # client build + SSR build + prerender -> dist/
npm run lint
npm run deploy     # GitHub Pages
```
